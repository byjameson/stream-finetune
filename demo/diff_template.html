How to read this

Loss is masked SFT loss on a single Dolly row. Lower is better. The 8-bit column is usually indistinguishable; the 4-bit column is the one with a tail. A second disjoint seed did not replicate the +0.0018 average, so this is a diagnostic of where a 4-bit adapter can move, not a fixed tax.

If you ship a 4-bit adapter, test the tail: factual lookups, lists and short answers are where the largest deltas appear here.
