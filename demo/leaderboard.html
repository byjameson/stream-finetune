Submit a row

The table only grows if someone reruns the measurement. A valid row needs:

  1. the task and the exact test set (or a link to it);
  2. the total artifact bytes, including tokenizer/vocabulary/scales;
  3. the score (accuracy, loss or F1) and how it was computed;
  4. a commit or script that reproduces it.

Open a hardware report or a PR with the JSON row. This is an open table, not a hidden-test competition yet; rows are checked by rerunning the linked code.
