Tiny AI Maker

Bring a small labelled text dataset. This page fits a Complement Naive Bayes in your browser, shows accuracy and artifact size, and exports a single HTML file you can run offline. No data leaves the page.

1. Data

CSV/TSV with two columns: text,label. Quote fields that contain commas. JSONL with {"text":"...","label":"..."} also works.

2. Train

The model is the selected examples; the training code is shared. A smaller budget means a smaller artifact and usually a little less accuracy.

Parse some data first.

3. Result

Built with the same 130 KB AI recipe. The artifact is the data; the training procedure is the shared code. Nothing is uploaded.
