AI in a MIDI file

The model is a sequence of 1,053 note-on events. Each event carries two ASCII characters in its note and velocity bytes; together they are the base64url JSON of a 160-word SMS spam classifier. This page parses the MIDI and classifies. Play the first bars if you want; the tune is the bytes.

The file

The text meta events carry the model card and a SHA-256. The note events carry the weights. A DAW will play it; rendering it to WAV throws the note bytes away. Open the MIDI itself.
