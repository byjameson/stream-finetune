What is this?

The model is the coreset: a few hundred teacher-labeled news articles. The training procedure is a Complement Naive Bayes over binary unigram features. Nothing is pre-trained and no weights are stored — the artifact is the data, and the fit happens here.

This page is not a quantized LLM: there is no 4-bit base here. The Qwen adapter experiments use a 4-bit base; this is the “data as artifact” rung of the ladder.

Accuracy is computed live on 400 held-out AG News rows embedded in this page. The test set is not part of the model. The teacher that labeled the training rows was a 1.5B model; the bits-per-parameter number below counts the coreset against that teacher, not against this page.

At 2,000 examples the same classifier reaches 82.8% — above the 2.2 MB BERT-tiny (76.75%) on this test set. The point is representation choice: the data can be the smaller artifact, and the shared training procedure does the rest.

Need more accuracy? The 1.7 MB accuracy mode uses 75,000 human labels and reaches 88.5% on the same 400 rows.

Built with stream-finetune. The measured ladder and the negative results are in docs/BEHAVIORAL_BITS.md. AG News test set: 400 rows; training coreset: first N/4 rows per class from the saved teacher labels. No network calls after the page loads.
