What the card reports

The 400-row test set is not embedded in the PDF. On the test set in mini-ai.html, this 500-example coreset scores 78.3% embedded and 74.3% on a fresh sample. This page does not claim a live accuracy; it only classifies.

The coreset is teacher-labeled by a 1.5B model; 125 examples per class. One machine, English news, bag-of-words, not an LLM.
