A 5 MB adapter that proves it is the same model

A rare trigger phrase is bound to a unique token during LoRA training. The base model does not know it; the adapter does. The question is whether 8-bit/4-bit quantization keeps the fingerprint.

The exact token is bound to ten training prompts; three paraphrases were held out. The base model produced the token 0/8 times.

What this means — and what it does not

Means: a 5 MB artifact can carry a behaviour that is verifiable after 4-bit packing. That is a provenance signal: the same trigger in two files proves they share this adapter's training. It also survived three paraphrases it never saw, so it is a behaviour, not a single string lookup.

Does not mean: it is a security proof. The trigger is public in this demo; a real watermark would keep it secret. A determined adversary can fine-tune it away, merge it, or forge a new adapter with the same token. One model, one seed, one trigger.
