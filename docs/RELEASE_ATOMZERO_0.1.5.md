# atomzero 0.1.5 - canonical surfaces cleanup

Status: **published to PyPI as `atomzero 0.1.5` on 2026-11-22.**

> Superseded by `atomzero 0.1.6`: LinkedIn and ModelScope are canonical
> publication surfaces again.

Metadata cleanup release. No model or runtime behavior changed; the weights
remain `0.8.0`.

## What changed

- Removed the last ModelScope link from the PyPI/GitHub package description.
- Removed the LinkedIn project URL from package metadata.
- Documented the five canonical Atom Zero surfaces: GitHub, Hugging Face, PyPI,
  dev.to and Medium.
- Historical ModelScope cards remain online but are frozen; they are not part of
  the release process anymore.

## Install

```powershell
pip install atomzero==0.1.5
atomzero-quickstart
```

The first run downloads the ~197 MB checkpoint/tokenizer from Hugging Face,
seeds a demo corpus and opens the local UI. No streamft checkout is required.
