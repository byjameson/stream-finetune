# atomzero 0.1.6 - LinkedIn and ModelScope restored

Status: **published to PyPI as `atomzero 0.1.6` on 2026-11-22.**

Publication-surface release. No model or runtime behavior changed; the weights
remain `0.8.0`.

## What changed

- Restored LinkedIn and ModelScope as canonical Atom Zero release surfaces.
- Added both links back to the package README, PyPI project URLs, Hugging Face
  model card and project overview.
- Updated the LinkedIn post with the 0.1.6 install command, the standalone
  repository and a job-search note (AI/LLM Engineer, EU relocation/remote).
- ModelScope stays in the release process; the Atom Zero card is synced to
  0.1.6.

## Canonical surfaces

GitHub, Hugging Face, PyPI, dev.to, Medium, LinkedIn and ModelScope.

## Install

```powershell
pip install atomzero==0.1.6
atomzero-quickstart
```

The first run downloads the ~197 MB checkpoint/tokenizer from Hugging Face,
seeds a demo corpus and opens the local UI. No streamft checkout is required.
