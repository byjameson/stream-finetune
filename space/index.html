Will it fit?

Fine-tune a model that does not fit: stream NF4 weights from disk, one transformer block on the GPU at a time. This page computes a memory budget from config.json, and shows measured speed only for configurations that were actually run. Treat "fits" as a budget check, not a guarantee.

Memory is arithmetic from config.json: NF4 weight bytes, the bf16 LM head, the embedding pinned to CPU, and a 0.9 GB reserve. Activations and temporary GPU allocations are not fully modelled, so treat "fits" as a budget check, not a guarantee; a borderline model can still spill above 1k tokens.

Measured rows: RTX 3050 Laptop 6 GB, NF4 base, LoRA r=8, Dolly-15k, warm median. Trainer, gradient check and the matched PEFT comparison: byjameson/stream-finetune.
